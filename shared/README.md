# Общие ресурсы

Ресурсы, которые могут использовать несколько частей Perkly.

- `assets/` — логотипы и общие изображения бренда.
- `mock_data/` — небольшие тестовые примеры данных.

Секреты и production-данные здесь хранить нельзя. Ресурс, используемый только одним клиентом, лучше держать рядом с этим клиентом.
