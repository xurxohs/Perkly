# Frontend: карта исходного кода

## Папки

- `app/` — страницы и маршруты Next.js App Router.
- `components/` — общие визуальные компоненты.
- `lib/` — API-клиент, авторизация, корзина и инфраструктурный код.
- `hooks/` — повторно используемое клиентское поведение.
- `content/` — статический контент и конфигурация публичных страниц.

## Основные точки

- `app/layout.tsx` — корневой HTML layout и глобальные провайдеры.
- `app/page.tsx` — главная страница.
- `lib/api.ts` — типы и функции запросов к backend.
- `lib/AuthContext.tsx` — пользовательская сессия.
- `lib/CartContext.tsx` — состояние корзины.

## Topka

- `app/feed/` и `app/news/` — пользовательская сторона контента.
- `app/admin/topka/` — управление публикациями.

Правило: страницы собирают интерфейс, `components` отвечает за повторное использование, а запросы к серверу должны проходить через `lib/api.ts`.
