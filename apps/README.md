# Приложения Perkly

В этой папке находятся пользовательские приложения единого продукта Perkly.

## Разделы

- [`mobile/PerklyApp`](mobile/PerklyApp/README.md) — нативное приложение для iPhone и iOS Widget.
- [`web/perkly`](web/perkly/README.md) — сайт, backend API и инфраструктура веб-части.

Оба клиента используют один backend и общие продуктовые сущности: пользователей, компании, офферы, промокоды, покупки, события и Topka-контент.
