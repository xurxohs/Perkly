# Perkly: тексты onboarding

Цель: сделать onboarding коротким, понятным и ценным для пользователя.

## Принципы

- Не объяснять продукт длинно.
- Говорить, что пользователь получит.
- Не использовать технические слова типа `B2CProfile`, `interests`, `activation`.
- Сразу вести к действию.

## Empty states

### Нет saved offers

```text
Сохраняйте офферы в каталоге, и они появятся здесь.
```

### Нет промокодов

```text
Активированные промокоды появятся здесь.
```

### Нет company для seller flow

```text
Подайте заявку компании, чтобы публиковать офферы и промокоды.
```

## Правила тона

Использовать:

- "офферы";
- "промокоды";
- "бонусы";
- "подборки";
- "сохранить";
- "активировать".

Избегать:

- "CDP";
- "B2C profile";
- "promocode activation entity";
- "transaction attribution";
- длинные инструкции.
