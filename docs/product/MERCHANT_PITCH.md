# Perkly: pitch для бизнеса

## Короткий pitch

Perkly помогает бизнесу запускать офферы и промокоды, видеть реальные активации и связывать скидки с покупками.

Это не просто витрина. Это канал продаж с аналитикой.

## Для кого

Perkly подходит для:

- локальных заведений;
- digital-сервисов;
- продавцов подписок и цифровых товаров;
- брендов, которые хотят запускать промокампании;
- компаний, которым нужно измерять эффективность скидок.

## Проблема бизнеса

Обычная скидка часто не даёт понятной картины:

- кто увидел предложение;
- кто сохранил;
- кто активировал промокод;
- кто скопировал;
- кто реально купил;
- какой промокод сработал лучше.

Perkly закрывает эту цепочку.

## Что получает бизнес

### Офферы

- Публикация товаров/услуг.
- Цена, категория, описание.
- Возможность продвигать оффер.

### Промокоды

- Статические и динамические промокоды.
- Лимит активаций.
- Лимит на пользователя.
- Дата начала и окончания.
- Привязка к конкретному офферу или всей компании.

### Аналитика

- Количество активаций.
- Процент копирования.
- Процент использования.
- Количество использованных активаций.
- Использование лимитов.
- Связь промокода с покупкой.

### Контроль

- Компания проходит модерацию.
- Seller tools доступны только активной компании.
- Промокод можно поставить на паузу или архивировать.

## Как это выглядит для клиента

```text
Клиент видит оффер -> активирует промокод -> покупает -> бизнес видит результат
```

## Как это выглядит для бизнеса

```text
Бизнес создает оффер -> выпускает промокод -> следит за аналитикой -> оптимизирует кампанию
```

## Почему это выгодно

- Можно быстро запускать кампании.
- Можно ограничивать промокоды.
- Можно понимать, какие офферы работают.
- Можно измерять не только просмотры, но и реальные покупки.
- Можно работать сразу с iOS/web/Telegram пользователями.

## Пример демо-оффера

Пример:

```text
Название: Weekend Coffee
Скидка: 15%
Лимит: 100 активаций
Лимит на пользователя: 1
Период: пятница-воскресенье
Цель: привести новых клиентов в выходные
```

После запуска бизнес видит:

- сколько пользователей активировали промокод;
- сколько скопировали;
- сколько использовали;
- какая конверсия в покупку.

## Финальная фраза

Perkly превращает скидки из хаотичной рекламы в управляемые B2B/B2C кампании с измеримой конверсией.
