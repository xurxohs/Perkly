# Perkly: короткий продуктовый one-pager

## Что такое Perkly

Perkly — это B2B/B2C платформа для офферов, промокодов, цифровых товаров и локальных предложений. Пользователь получает персональные скидки и бонусы, а бизнес получает канал продаж, промокоды, аналитику и управляемую витрину.

## Проблема

Пользователи видят слишком много разрозненных скидок, купонов и рекламных предложений, но редко понимают, что реально выгодно и где это удобно использовать.

Бизнесы, особенно малые и локальные, часто не имеют простого инструмента для:

- запуска промокодов;
- отслеживания активаций;
- связи скидки с реальной покупкой;
- анализа конверсии;
- управления цифровыми офферами.

## Решение

Perkly объединяет маркетплейс, промокоды, сохранённые офферы, B2C-профиль, B2B-компанию, покупку и аналитику в одну систему.

Пользовательский сценарий:

```text
Нашёл оффер -> сохранил -> активировал промокод -> купил -> получил доступ или Wallet pass
```

Бизнес-сценарий:

```text
Создал компанию -> добавил оффер -> выпустил промокод -> увидел активации/копирования/использования -> получил продажи
```

## Что уже готово

### Бэкенд

- B2B/B2C база: `Company`, `B2CProfile`, `UserInterest`, `SavedOffer`.
- Полный промокодный цикл: создание, активация, копирование, использование, аналитика.
- Checkout с `promocodeActivationId`.
- Сохранённые офферы на сервере.
- B2C profile/interests API.
- Company apply/status.
- Admin/security hardening.

### Веб

- Seller dashboard.
- Promocode management.
- Cart с промокодами.
- Profile с saved offers и activated promocodes.
- Admin/company moderation.

### iOS

- Сохранённые офферы синхронизируются с backend.
- На экране оффера есть активация промокода.
- Корзина применяет активированные промокоды.
- Seller flow умеет создавать, редактировать и менять статус промокодов.
- Company application/status gate закрывает seller-инструменты до модерации.
- Есть настройки B2C-персонализации.
- Apple Wallet UI.

## Почему это B2B/B2C платформа

Perkly работает сразу на двух сторонах рынка:

```text
B2C: User -> B2CProfile -> Interests -> SavedOffer -> Purchase
B2B: Company -> Offer -> Promocode -> Activation -> Transaction -> Analytics
```

Ценность растёт с каждой стороной:

- больше бизнесов -> больше офферов;
- больше пользователей -> больше активаций;
- больше данных -> лучше рекомендации;
- больше покупок -> сильнее analytics для бизнеса.

## Дифференциация

- Не просто каталог скидок, а связка `offer + promocode + activation + transaction`.
- Сохранённые офферы на сервере между iOS/web/Telegram.
- B2B company layer с модерацией.
- Seller analytics по реальным промокодным действиям.
- Возможность расшириться в Telegram Mini App, web и native iOS.
