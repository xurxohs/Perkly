# Perkly: сценарий демо на 3 минуты

Цель: показать Perkly как B2B/B2C платформу, а не просто каталог скидок.

## Структура демо

```text
0:00-0:30  Ценность для пользователя
0:30-1:20  Активация промокода и покупка
1:20-2:10  Ценность для бизнеса
2:10-2:45  Company/admin слой доверия
2:45-3:00  Видение продукта
```

## 0:00-0:30 — Ценность для пользователя

Открываем iOS app.

Говорим:
> Perkly помогает пользователю находить выгодные цифровые и локальные офферы, сохранять их, активировать промокоды и покупать в одном месте.

Показываем:

- Home/Catalog.
- Offer cards.
- Promo badge.
- Saved heart.

Главная мысль:
> Пользователь не просто смотрит скидку. Он может сохранить оффер, активировать промокод и довести всё до покупки.

## 0:30-1:20 — Активация промокода и покупка

Открываем offer detail.

Показываем:

- блок "Доступные промокоды";
- кнопку "Активировать";
- saved state;
- add to cart.

Говорим:
> У промокодов есть полноценная backend-логика: активация, копирование, использование и связь с покупкой.

Открываем cart.

Показываем:

- выбранный activated promocode;
- пересчёт суммы;
- checkout.

Главная мысль:
> Perkly связывает промокод не только с кликом, а с транзакцией.

## 1:20-2:10 — Ценность для бизнеса

Открываем seller dashboard.

Показываем:

- список офферов;
- список промокодов;
- create/edit promocode;
- status active/paused/archived;
- analytics summary.

Говорим:
> Для бизнеса Perkly — это не просто публикация скидки. Это инструмент управления промокодами, лимитами и конверсией.

Показываем:

- STATIC/DYNAMIC code;
- max activations;
- per-user limit;
- validFrom/validTo;
- activations/copy/use.

Главная мысль:
> Бизнес видит, какие промокоды активируются, копируются и реально используются.

## 2:10-2:45 — Company/admin слой доверия

Показываем company application/status.

Говорим:
> Seller-инструменты привязаны к компании. Компания проходит модерацию, получает статус, и только активная компания может полноценно продавать.

Показываем:

- company apply;
- pending moderation;
- active state.

Главная мысль:
> Это B2B слой доверия: Perkly может модерировать продавцов и управлять доступом.

## 2:45-3:00 — Видение продукта

Говорим:
> Следующий шаг — усилить персонализацию и аналитику: interests, saved offers, промокодные активации и покупки дают основу для рекомендаций и B2B-кампаний.

Финальная фраза:
> Perkly становится платформой, где пользователь получает персональные выгоды, а бизнес получает управляемый канал продаж и аналитику.

## Если live API недоступен

- показать каталог;
- показать сохранённые офферы;
- показать seller UI для промокодов;
- показать `ARCHITECTURE_MAP.md`;
- объяснить backend endpoints и production deploy.
