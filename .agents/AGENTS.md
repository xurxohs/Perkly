## 📌 Development Instructions

* **VS Code Workspace:** Open [startap.code-workspace](file:///Users/shoxrux/Desktop/STARTAP/startap.code-workspace).
* **Locally Running Servers:** Use `start_all.sh`.
* **VPS Deployment:** Use `deploy.sh`.
* **Product Documentation:** Shared product and release documents live in `docs/product`.
* **Topka:** Keep Topka-related screens, assets, routes, and backend modules inside the relevant Perkly application. Do not split them into a standalone project unless explicitly requested.
