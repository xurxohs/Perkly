# Заметки Obsidian

Эта папка — простой центр управления проектом для человека, а не часть исполняемого приложения.

- `00 — Главная` — стартовая навигация.
- `01 — Текущий фокус` — три главных приоритета.
- `02 — Задачи` — рабочий список.
- `03 — Идея продукта` — проблема, решение и ценность.
- `04 — Карта проекта` — расположение кода.
- `05 — Журнал решений` — история важных решений.

Настройки самого Obsidian находятся в корневой `.obsidian`.
