# Карта проекта

## Основные части

- `apps/mobile/PerklyApp` — актуальное iOS-приложение
- `apps/web/perkly/frontend` — web-интерфейс
- `apps/web/perkly/backend` — backend и API
- `docs/product` — общая продуктовая и релизная документация
- `shared` — общие ресурсы и тестовые данные

## Topka внутри Perkly

Topka — модуль контента и событий внутри продукта. Связанные экраны и ресурсы находятся в iOS/Web, а API и администрирование — в общем backend Perkly.

## Логика системы

```text
iOS / Web / Telegram
          ↓
         API
          ↓
      PostgreSQL
```

## Основные контуры

```text
B2C: User → Interests → SavedOffer → Purchase
B2B: Company → Offer → Promocode → Activation → Analytics
```
